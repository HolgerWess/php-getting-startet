# PHP Getting Started

Dieses Repository enthält ein einfaches PHP-Skript für ein Kontaktformular mit Validierung.

## Verwendung

Starten Sie den integrierten Webserver von PHP und rufen Sie das Formular im Browser auf:

```
php -S localhost:8000 contact.php
```

Anschließend können Sie das Formular unter http://localhost:8000 aufrufen und testen.
